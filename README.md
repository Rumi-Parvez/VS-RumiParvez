## ⚡ Install Extensions from the Terminal

Make sure the `code` command is available in your terminal. Then install any verified extension by its ID:

```powershell
code --install-extension bradlc.vscode-tailwindcss
code --install-extension esbenp.prettier-vscode
code --install-extension christian-kohler.path-intellisense
code --install-extension christian-kohler.npm-intellisense
code --install-extension formulahendry.auto-rename-tag
code --install-extension formulahendry.auto-close-tag
code --install-extension ritwickdey.LiveServer
code --install-extension xabikos.JavaScriptSnippets
code --install-extension xabikos.ReactSnippets
code --install-extension idandrd.idandrd-vscode-react-typescript
code --install-extension wts-dev.wts-react-js-snippets
code --install-extension vscode-icons-team.vscode-icons
code --install-extension PKief.material-icon-theme
code --install-extension zhuangtongfa.Material-theme
code --install-extension SumitSaha.learn-with-sumit-theme
code --install-extension ms-vscode.PowerShell
code --install-extension ms-vscode-remote.remote-containers
code --install-extension ms-azuretools.vscode-containers
code --install-extension formulahendry.code-runner
code --install-extension njpwerner.autodocstring
code --install-extension sst-dev.opencode
```

Some entries in the original list have similarly named Marketplace extensions. For **React Extension Pack**, **JavaScript/TypeScript React/Next.js Snippet**, **Auto Import Sorter**, **Search node_modules**, **Atom One Dark Theme**, **Lenghool Color Theme**, and **Monokai**, use the links above to confirm the exact publisher and extension before installing. This avoids installing a similarly named extension by mistake.

To list extensions currently installed on your machine:

```powershell
code --list-extensions
```

To save your installed extension IDs to a text file in PowerShell:

```powershell
code --list-extensions | Set-Content vscode-extensions.txt
```
